# 🚀 BizNest

A simple web-based toolkit designed to help users create and organize basic business planning materials.

## ✨ Features

- 📋 Business Plan Generator
- 📄 One-Page Business Plan
- 🎨 Poster Generator
- 🌐 Simple and responsive web interface

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
