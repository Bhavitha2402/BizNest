# 🚀 BizNest

**AI-powered business tools in one place.**

BizNest is a web-based toolkit that helps users quickly create business planning and promotional content using AI-powered tools.

🌐 **Live Demo:** https://bhavitha2402.github.io/BizNest/

## ✨ Features

### 📋 Business Plan Generator
Create complete business plans quickly with the help of an AI-powered tool.

### 🎨 Poster Design Generator
Generate promotional poster designs for business ideas and campaigns.

### 📄 One Page Plan Generator
Turn a business idea into a concise one-page business plan.

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- GitHub Pages
- Relevance AI
